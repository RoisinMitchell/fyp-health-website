A CNN-Based Web Tool for Common Skin Condition Detection

Fionn Grant O'Sullivan

A web application in which an image can be uploaded to a machine learning model and receive the top 5 most likely common skin conditions that match the lesion present in the input image. Complete with explainability through heatmap generation.

Project Snapshot

Exploring image-based early screening

A web application developed with an aim toward dermatological accessibility issues in mind. Upon opening the application, the user will be able to upload an image of a skin lesion they are struggling with. Through the simple click of a button, the user will receive an analysis of the common conditions the lesion is most likely to belong to.

At the heart of the application is the convolutional neural network (CNN) algorithm. This was trained on a vast dataset of images which were procured to imitate smartphone-style photo conditions, rather than being taken with a dermatoscope, which is a specialised dermatological tool used to take extremely high-quality photos of skin lesions.

Many ML algorithms which seek to bridge the gap in urgent dermatology access are trained using these high-quality, dermatoscope-captured images. However, this is counter-intuitive, as dermatoscopes are expensive and require extensive training to use. An algorithm which focuses on images at a distance and quality that could be captured with a smartphone is considerably more feasible than one which is trained on images captured with a relatively inaccessible tool. The application is a concept which could be deployed as a preliminary support and screening tool for those affected by excessively long dermatologist waiting lists.

The application possesses a graph that accompanies the top 5 most likely results succeeding the input of the image, as well as a Gradient-weighted Class Activation Mapping (Grad-CAM) based heatmap, depicting the areas of the input image that factored the most into the model's final decision. Many tools like this concept are not supported by a component which explains the model's decisions. This was added to improve the trustworthiness in what was created to be an explainable, non-specialist, clinical support tool.

Focus

Convolutional neural networks for identifying common skin condition patterns in images.

Audience

Individuals without specialist dermatological access who require preliminary screening support.

Demo

A demonstration of the application's image analysis capabilities with a group of images.
