Empowering Informal Caregivers: A Discrete Sensor and Mobile Application for Remote Fall Detection with Older Adults

Maeve Bray

This project is a user centred fall detection system called Guardian. It is a system that combines a mobile application and a motion sensor connected to an Esp-32 microcomputer that will be used to notify informal caregiving of older adults that are at risk of dangerous falls. The sensor sends a signal via Wi-Fi to the app which increases range of motion for an informal care giver and decreases the stigma around wearable devices for older adults.

Project Snapshot

Extending reassurance beyond the home

Falls represent a leading cause of injury among older adults in Ireland, with approximately 30% of those over 65 affected annually. For bed-confined individuals cared for by informal family caregivers, the absence of reliable, long-range fall detection compounds both physical risk and psychological burden for all parties involved. Existing solutions including wearable pendants, pressure mats, and baby monitors have been shown to be limited in range, dependent on user action, and socially stigmatising for older adults.

This project presents Guardian, a discrete fall detection system comprising a passive PIR motion sensor and a cross-platform mobile application designed for informal caregivers. The system leverages an ESP32 microcontroller connected via Firebase's Realtime Database to deliver immediate push notifications to a caregiver's smartphone, regardless of physical distance. The mobile application, developed using React Native and the Expo framework, provides real-time incident logging, timestamped fall records, caregiver note-taking, and activity statistics through an accessible, colour-coded interface.

The Guardian system aims to resolve the tension between safety and autonomy by operating invisibly in the background, in accordance with Person Centred Care and ambient technology principles.

Focus

Creating a hands-free, long-range fall detection system that can transmit signals via Wi-Fi and activate a remote alarm.

Audience

Informal Caregivers, Older adults, family members of older adults, nursing home staff, medical staff and people that are interested in fall detection software and systems.

Demo

A display of the app and all its features where users can navigate the app and use the test trigger function to simulate the real time notification and flow of the app when the sensor has been triggered. The sensor will be on display but not in use due to high amounts of foot traffic throughout the day. A video will be displayed on a screen on repeat showing the full walkthrough of the system where the senor is shown to be used and with triggers of the motion sensor showing how the app responds to a motion.
