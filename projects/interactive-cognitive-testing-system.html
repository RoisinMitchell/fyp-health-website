Designing an Interactive Cognitive Testing System

Thomas Broderick

Project Snapshot

Balancing assessment, usability, and context

MindSpark is an interactive cognitive testing system centred on the Go/No-Go test, which is a widely established cognitive test used in both research and clinical settings for measuring attention, response inhibition, and impulse control. Rather than presenting the test as a standalone clinical-style assessment, MindSpark places it within a more approachable and user-friendly digital experience that supports users before, during, and after the test.

The system is designed to make cognitive testing easier to understand and engage with. It includes clear onboarding, guided practice, simple navigation, and a structured test flow that helps users feel oriented and confident as they move through the experience. The interface aims to reduce unnecessary friction so that interaction feels intuitive rather than stressful or confusing.

A central part of MindSpark is its multimodal design. Users can interact with the test through touch-based or verbal interaction, and the experience is supported by both visual and audio feedback. This creates a more flexible and accessible system by reducing reliance on touch-only interaction and allowing the test to better support different user needs and contexts of use.

The project also places strong importance on context-aware feedback and personalisation. Instead of reducing performance to raw scores alone, the system considers factors such as alertness and presents information in a way that feels more meaningful and easier to interpret over time. Alongside the test itself, the wider application includes features such as progress tracking, goal setting, rewards, and tailored feedback which helps cognitive testing feel more understandable, engaging, and human-centred.

Focus

An accessible and interactive cognitive testing system designed around usability, multimodal interaction, and context-aware feedback, focusing specifically on a redesigned Go/No-Go cognitive test.

Audience

The audience for this application includes older adults and individuals interested in tracking or exploring their cognitive performance through a more accessible, supportive, and intuitive digital testing experience.

Demo

A live walkthrough of an interactive prototype of MindSpark showing how the Go/No-Go test fits within the wider cognitive testing application, followed by a demonstration of the full test journey supported by backend functionality from start to finish. The demo will present touch and voice interaction, audio-visual feedback, and clear, context-aware results. For the purposes of this demonstration, the testing flow will be simulated on a MacBook Pro, with touch interactions represented through mouse clicks, in order to communicate the intended mobile interaction style within the project's scope.
