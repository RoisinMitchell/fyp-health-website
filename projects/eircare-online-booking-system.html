Eircare: Online Booking System for General Practitioners

Caylum Hurley

Eircare is a full-stack GP appointment booking platform built for the Irish healthcare context. Patients can search for nearby doctors, book in-person or virtual consultations, and manage their appointments, while doctors control their availability and GPs can claim verified practice profiles imported directly from the HSE database.

Project Snapshot

Reducing friction in appointment booking

Eircare addresses a real gap in Irish primary care access: the lack of a unified, modern booking system for GP practices. The platform supports three distinct user roles: patient, doctor, and admin, each with a tailored experience built around real workflows in the Irish healthcare system.

Patients register and can immediately search for GPs by location, with results ranked by proximity using haversine distance calculations powered by GeoTools and real-world coordinates sourced via the OpenStreetMap Nominatim geocoding API. Each doctor profile displays availability, consultation types, and virtual appointment support. Patients can book slots, request translator services, view their appointment calendar, and join virtual consultations directly in-browser via Jitsi Meet integration.

Doctors manage a granular weekly availability schedule: setting hours, marking breaks, and toggling virtual availability. They can view their upcoming appointments with full patient context. New GPs registering on the platform can claim unclaimed practice profiles that were bulk-imported from the HSE's official find-a-gp portal using a custom Python web scraper, giving the system a real dataset of Irish GP practices from day one.

Admins oversee doctor verification, reviewing and approving or rejecting registrations based on submitted credentials such as medical council numbers. This ensures only verified practitioners appear to patients.

The backend is built with Spring Boot and Java 21, secured by JWT-based authentication with role-level access control. The frontend is a React 19 SPA and Bootstrap for responsive UI. The entire stack is containerised with Docker Compose, with Nginx handling production routing.

Focus

A location-aware, end-to-end GP appointment booking system tailored specifically to the Irish healthcare system, covering patient discovery, online booking, virtual consultations, and doctor verification.

Audience

Irish patients seeking accessible GP booking, GPs looking to digitise their scheduling, and healthcare administrators managing practitioner verification.

Demo

Live demonstration of a patient searching for a nearby GP by location, booking a virtual appointment, and joining a Jitsi video consultation, end-to-end in one flow.
