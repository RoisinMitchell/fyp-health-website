Stage 01 | Staying Healthy

Mental Health Tracker Web App

Emma Myo Nyunt

Mental Health Tracker Web App, which I have named 'Mood Garden' is a web app I built to help people check in with themselves. You are prompted to pick a companion pet and to name it for anonymity. And on this web app, you can log how you're feeling day to day - mood, stress, sleep, appetite, movement - and everything stays in your browser, so it feels private. There's also journaling, a simple to-do list, calendars and charts so you can see patterns.

Project Snapshot

Supporting reflection and healthier routines

A personal dashboard, with a colourful and calm feeling UI, as well as some mindful tips based on the data that is logged. Data is stored locally (by pet/profile), you can switch between a light and dark mode depending on preference. The home area pulls together today so you can see at a glance what you've already logged and what you might still want to add, or log entries for previous days you might've missed.

Focus

The focus is making daily mental-health check-ins feel approachable and visual, so users can notice patterns and build consistency without needing a complicated setup.

Audience

The main audience is for young adults, and anyone who wants a gentle, private way to track habits and moods, in the browser without signing up for another heavy platform.

Demo

For the demo, I will showcase what it looks like to create a new profile, and showing the bare bones of the web app without any data logged. Then I will walk through a profile that already exists on the browser, showing what each page looks like with entries already filled in for previous days, as well as logging new entries. As well as showing the insights, tips, settings and the dashboard.
